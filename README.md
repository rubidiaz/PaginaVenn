# Venn-Webseite – Erstes Projekt mit HTML und CSS
Dieses Projekt war meine erste praktische Annäherung an die Webentwicklung. 
Es besteht aus einer informativen Webseite, die mit HTML und CSS gestaltet wurde 
und erste Ansätze eines responsiven Designs beinhaltet. 
Das Projekt wurde im Jahr 2021 im Rahmen einer Schulung bei Tech Academy erstellt.

## 🚀 Verwendete Technologien
- HTML5  
- CSS3  
- Responsive Design (Media Queries)  
- Grid- und Flexbox-Layout

## 🎯 Ziel des Projekts
Das Ziel dieses Projekts war es, ein grundlegendes Verständnis für den Aufbau 
einer Webseite zu entwickeln, Gestaltungselemente anzuwenden und einfache 
Strukturen für Benutzeroberflächen umzusetzen.

## 📘 Was ich durch dieses Projekt gelernt habe
- Strukturierung von Inhalten mit grundlegenden HTML-Tags  
- Anwendung eigener Styles mit CSS  
- Erste Umsetzung von responsive Design mit Media Queries  
- Verwendung von Grid und Flexbox für ein visuelles Layout

## 🛠 Verbesserungen, die ich heute vornehmen würde
- Neustrukturierung des CSS in klarere Module  
- Umsetzung mit einem Mobile-First-Konzept  
- Einsatz flexibler Größen anstelle fester Pixelwerte  
- Optimierung der Bilder und Ressourcen
